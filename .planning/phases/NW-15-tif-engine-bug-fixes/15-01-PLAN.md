<objective>
Fix two correctness bugs in js/lib/forecast-tif.js that cause TIF predictions to be
computed on incorrect data, and verify each fix with a targeted unit test.

Purpose: After Phase 14, two bugs were identified — (FIX-01) findBedtimeDayRecord
can select the wrong day record when bedtime slots mix bare HH:MM strings with ISO
event objects; (FIX-02) rejected-day pre-filtering silently reduces the auto-trim
budget by shrinking N, defeating manualExcludedCount semantics. Both cause subtle
prediction drift that worsens over time as history grows.

Output: Patched forecast-tif.js with both bugs fixed, plus new unit tests in
tests/unit/forecast-tif.test.js confirming the correct behaviour.
</objective>
