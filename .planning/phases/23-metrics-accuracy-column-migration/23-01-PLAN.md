<objective>
Add a new per-day TIF prediction-window table to the Accuracy screen, appended below the existing TIF summary table, showing the 12 per-event min/max/confidence columns (wake, nap-start, nap-end, bedtime) that currently live on the Metrics screen. This is the "add the new home" half of the UI-11 migration — the Metrics screen removal happens in plan 23-02, which depends on this plan landing first so the columns are never simultaneously absent from both screens.

Purpose: Accuracy screen becomes the single place per UI-11's intent: "how well predictions performed," using data the screen already computes (computeTifBoundsHistory) but has never surfaced per-day.
Output: `buildTifPerDayTable()` in accuracy-screen.js, wired into `renderTifAccuracy()`; supporting CSS; new/updated E2E coverage in accuracy-screen.spec.js.
</objective>
