## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-04 | Tampering / Denial of Service | `blendWindowDays`/`blendTrimPct`/`blendShrinkage` range validation | medium | mitigate | `RULES` enforces `[14,180]`/`[0,40]`/`[0.0,1.0]` in `mode:'save'` (rejects out-of-range) and silently resets to a safe default in `mode:'load'` (a corrupted/hand-edited localStorage blob cannot inject a degenerate value like `blendWindowDays:0` or `blendTrimPct:100`, both of which would make `trimmedBand`'s budget arithmetic in `forecast-blend.js` discard the entire input array and return `null` for every band — a silent-degradation DoS-by-degenerate-input, not a crash, but still prevented at the schema boundary). |
| T-25-05 | Tampering | `checkField`'s new `'number'` case | low | accept | `Number.isFinite` rejects `NaN`/`Infinity`/non-numeric strings identically to how `'integer'` already rejects them via `Number.isInteger` — no new coercion surface beyond what the existing `'integer'` case already accepts (`Number(raw)` on a string). |

</threat_model>
