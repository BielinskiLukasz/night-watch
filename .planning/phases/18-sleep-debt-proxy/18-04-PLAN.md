<objective>
Fix two UAT gaps in the Sleep Debt Proxy (Phase 18) implementation.

G-18-5 (UX label): The column header 'S.Debt' does not communicate it is a 7-day rolling sum.
Rename the label to 'S.Debt(7d)' in the COLUMNS array (js/ui/metrics-screen.js line 54).

G-18-6 (logic bug): buildRollingSection passes slice.slice(0, i+1) to sleepDebtProxy — bounded to
the rolling window (max 7 records). sleepDebtProxy's cold-start guard (return null when fewer than
windowDays=7 qualifying records) misfires for all rows except the last, causing '—' in all rolling
aggregate S.Debt cells. Fix: use sliceOffset so the full nonRejectedDays history up to each row's
original position is passed.

Purpose: Users can see meaningful S.Debt values in the 7-day and 14-day rolling aggregate sections.
Output: Two source-file edits and updated/added E2E test coverage.
</objective>

**Edit B — G-18-6 sliceOffset (buildRollingSection, ~line 441-447):**
Inside buildRollingSection, immediately before the loop that augments rolling rows with
sleepDebt, add the sliceOffset computation and replace the bounded slice call.

Current code (lines ~441-447):
  // Step 4a: augment rolling rows with sleepDebt (MET-14).
  // All entries in slice are already non-rejected (nonRejectedDays pre-filtered).
  // For row at index i, pass the sub-slice [0..i] so sleepDebtProxy's
  // filter-then-slice window accumulates correctly oldest-to-newest.
  for (let i = 0; i < result.rows.length; i++) {
    result.rows[i].sleepDebt = sleepDebtProxy(slice.slice(0, i + 1), 7, snap.targetSleepMinutes);
  }

Replace with:
  // Step 4a: augment rolling rows with sleepDebt (MET-14).
  // sliceOffset maps each rolling row back to its position in the full nonRejectedDays
  // array so sleepDebtProxy receives the full history up to that day — not just the
  // bounded rolling window. Without this, the cold-start guard (< 7 qualifying records)
  // misfires for all but the last row in the 7-day section (G-18-6).
  const sliceOffset = Math.max(0, nonRejectedDays.length - nDays);
  for (let i = 0; i < result.rows.length; i++) {
    result.rows[i].sleepDebt = sleepDebtProxy(
      nonRejectedDays.slice(0, sliceOffset + i + 1),
      7,
      snap.targetSleepMinutes
    );
  }

Do not touch the aggregate-debt computation that follows (lines ~449-461) — it is correct.
Do not change the buildRollingSection function signature or any other logic.
