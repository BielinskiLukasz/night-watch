<objective>
Add `eventAccuracyScore(forecastMinutes, actualMinutes, toleranceMinutes)` to `js/lib/accuracy.js` using the ACC-02 linear-decay formula, and rewrite `computeAccuracy()`/`buildAccuracyResult()` so every event type's accuracy is the arithmetic mean of per-event scores (ACC-03) instead of the old binary within-max-delta / within-half-delta / inside-band hit-miss counters (ACC-01, ACC-02, ACC-03, ACC-04). Purpose: this is the algorithmic heart of the phase. `accuracy-tif.js`'s bedtime split (Plan 22-02) and `accuracy-screen.js`'s rendering (Plan 22-03) both build directly on the final `AccuracyResult` shape this plan produces. Proving the formula and the shape here first — verified, with real tests — before either downstream plan starts avoids building a second backtesting engine or a UI against a shape assumption that turns out wrong.

Output: `eventAccuracyScore()` exported from `js/lib/accuracy.js`; `computeAccuracy()` returning `{ wake, bedtime, bedtimeNapDay, bedtimeNoNapDay, napStart, napEnd, overallScore }` with zero remaining hit/miss counter fields.
