## Phase 8 — New Surface Elements

### Update Banner (D8-06)

A fixed top bar that appears when a new service worker is waiting.

- **Position:** Fixed, top: 0, left: 0, right: 0, z-index: 200 (above bottom-nav's z-index: 100)
- **Height:** 40px
- **Background:** `#1e293b` (dark surface — distinct from body `#fafafa` to ensure visibility)
- **Text color:** `#f8fafc` (near-white)
- **Text:** "Update available" (static label via textContent)
- **Button label:** "Reload" (accent-colored, minimum 44px touch target)
- **Behavior:** Shown only when SW `waiting` state is detected; hidden after user taps Reload or dismisses
- **Body offset:** When visible, body/app gains `padding-top: 40px` to prevent content overlap
- **Security:** All content via textContent (no innerHTML). No dynamic content needed.

### file:// Note (D8-08)

A one-time dismissable note shown when `location.protocol === 'file:'`.

- **Position:** Inline, below header, above main app content (not fixed)
- **Style:** Subtle — muted background `#f8fafc`, border `#e2e8f0`, border-radius 0.375rem, padding 8px 16px
- **Text:** "Running from local file — install from the web version for offline support." (textContent)
- **Dismiss button:** "×" (aria-label="Dismiss"), right-aligned, 44px touch target minimum
- **Persistence:** Dismissed state stored in localStorage key `nw_file_note_dismissed`
- **Security:** All content via textContent (no innerHTML).

### Tab-Switch Fade (D8-11)

Screen sections (`#today-screen`, `#history-screen`, `#charts-screen`, `#accuracy-screen`) gain entrance transitions.

- **Property:** `opacity: 0 → 1`
- **Duration:** 150ms
- **Easing:** `ease-in-out`
- **Implementation:** CSS only — add `transition: opacity 150ms ease-in-out` to screen sections; JS sets opacity:0 before display, then opacity:1 after display change via `requestAnimationFrame`.

### Chart SVG Transitions (D8-12)

When chart data changes (stage switch, new event logged), SVG child elements animate in.

- **Opacity fade:** All SVG elements (rects, circles, text) — `transition: opacity 200ms ease-in`. Elements start at opacity:0 on re-render and ease to opacity:1.
- **Polyline draw-in:** Sleep-length line chart polyline uses `stroke-dasharray` / `stroke-dashoffset` animation — `@keyframes drawLine { from { stroke-dashoffset: var(--line-length); } to { stroke-dashoffset: 0; } }`. Duration: 300ms, easing: ease-out.
- **Implementation:** CSS `@keyframes` on SVG elements only. No JS animation library. Matches calm/ambient register.
- **Constraint:** `createElementNS` SVG generation (D7-08) is preserved — CSS classes are applied to generated elements.

### Settings Modal Groups (D8-14)

Current three fieldsets (Profile / Time & Day / Forecast tuning) are reorganized into four logical groups:

1. **Subject & Display** — Subject name, time format (CFG-01, CFG-09)
2. **Day Structure** — Day cutover hour, view grouping (CFG-08)
3. **Forecast & Prediction** — Auto outlier, max delta, min days, rolling window, stat blend (CFG-02..07)
4. **Data** — Import CSV, Import JSON, Export JSON, rejected days note (DATA-01..03)
5. **Stages** — Stage CRUD (STAGE-01; existing fieldset, reordered to bottom)

Visual treatment: 16px gap between fieldsets, fieldset border `#e2e8f0`, legend font-size 14px weight 600 color `#334155`. Internal label spacing: 8px gap between stacked labels.

All inline SVG icons (bottom-nav, quick-log buttons, Settings trigger) must conform to one unified style after the Phase 8 icon pass:

| Property | Value |
|----------|-------|
| ViewBox | `0 0 24 24` |
| Stroke width | 1.5px |

| Stroke linejoin | `round` |

| Color | `currentColor` (inherits from button color) |
