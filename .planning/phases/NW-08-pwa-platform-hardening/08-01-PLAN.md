## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SW fetch handler → network | SW intercepts all fetches; malicious precache URL could cause install failure |
| localStorage → file:// note | localStorage key read as truthy/falsy only; no arbitrary execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01-01 | Tampering | sw.js PRECACHE_LIST (too broad scope) | high | mitigate | scope "./" in manifest.json limits SW to app subdirectory; PRECACHE_LIST excludes test/planning paths |
| T-08-01-02 | Tampering | sw.js SKIP_WAITING message handler | medium | mitigate | Handler checks event.data.type === 'SKIP_WAITING' exactly; browser enforces same-origin postMessage; no eval or dynamic code execution |
| T-08-01-03 | Spoofing | SW serving stale code indefinitely | medium | mitigate | Versioned CACHE_NAME "nightwatch-v1"; deleteOldCaches on activate removes all non-matching caches |
| T-08-01-SC | Tampering | scripts/generate-icons.js one-off script | low | accept | Script is a dev helper only, never runs in CI or in the deployed app; no npm runtime deps introduced |
</threat_model>
