## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DOM → js/store/event-log.js | User clicks deliver `type` strings to the store; must be validated (V5) |
| js/store/event-log.js → js/adapters/storage-local.js | Store hands a serializable `db` object; adapter must handle persistence errors (V7) |
