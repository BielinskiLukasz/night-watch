  <behavior>
    Cases (all use { date: 'YYYY-MM-DD', ... } record shapes):

    annotateIntense([{date:'2024-01-15'}], {intenseDays:['2024-01-15']})
      → [{date:'2024-01-15', intense:true}]

    annotateIntense([{date:'2024-01-15'}], {intenseDays:['2024-01-16']})
      → [{date:'2024-01-15', intense:false}]

    annotateIntense([{date:'2024-01-15'}], {intenseDays:[]})
      → [{date:'2024-01-15', intense:false}]  (fast-path: no map of includes needed)

    annotateIntense([{date:'2024-01-15'}], {intenseDays: null})
      → [{date:'2024-01-15', intense:false}]  (non-array treated as empty)

    annotateIntense([{date:'2024-01-15'}], undefined)
      → [{date:'2024-01-15', intense:false}]  (no settings = no intense days)

    annotateIntense([r1, r2], settings) does not mutate r1 or r2 (spread creates new objects)

    daysByCalendar([...events], limit, settings) returns records with .intense set
    daysBySubjectiveNight([...events], cutoverHour, limit, settings) returns records with .intense set
  </behavior>

    ```javascript
    function annotateIntense(records, settings) {
      const intenseDays =
        settings && Array.isArray(settings.intenseDays)
          ? settings.intenseDays
          : [];
      if (intenseDays.length === 0) {
        return records.map(day => ({ ...day, intense: false }));
      }
      return records.map(day => ({
        ...day,
        intense: intenseDays.includes(day.date),
      }));
    }
    ```
