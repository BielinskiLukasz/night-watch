  <action>
Add four new exports to `js/lib/metrics.js` after the existing six duration helpers (after line 84).

**Function 1: totalActivity(day)** (D11-23)
- Compute: `activityBeforeNap(day) + activityAfterNap(day)`
- Return null if either component is null (no-nap days)
- Pure function, no side effects

**Function 2: activityAfterSleepFactor(day)** (D11-24)
- Compute: `totalActivity(day) / sleepDuration(day)`
- Return null if either component is null
- Ratios must not be computed for zero-duration sleep (return null; avoid division by zero)
- Pure function, no side effects

**Function 3: sleepAfterActivityFactor(day, prevDay)** (D11-25)
- Compute: `sleepDuration(day) / totalActivity(prevDay)`
- Return null if either component is null
- Return null if prevDay is absent/undefined (first day rule per D11-16)
- Return null if prevDay.totalActivity would be null (no nap in previous day)
- Avoid division by zero — return null if prevDay.totalActivity is 0
- Pure function, no side effects

**Function 4: aggregateMetrics(dayRecords)** (D11-26)
- Input: Array of pre-bucketed day records (order caller-provided, typically most-recent-first or oldest-first)
- Output: Object with keys: `{ rows, avg, min, max }` where:
  - `rows`: Array, one entry per day, each with all 9 metric values + 4 time values
  - `avg`: Object with average for each metric (null if no valid data)
  - `min`: Object with { value, date } for each metric (null if no valid data)
  - `max`: Object with { value, date } for each metric (null if no valid data)
- Logic (per CONTEXT.md D11-13..D11-16):
  - Exclude rejected days (where day.rejected === true) from all calculations
  - Exclude no-nap days from nap-column aggregates (Nap, Combined, Act→Nap, Nap→Bed, AAS, SAA columns)
  - For SAA: iterate dayRecords and pair each day with the previous one (oldest to newest internally); first day always null
  - Min/Max: return { value, date } where date is the ISO date string from that day's wake event (or bedtime if no wake)
  - Average durations: Math.round to nearest minute
  - Average ratios: compute normally, no rounding (2-decimal display is UI responsibility)
- Edge cases:
  - Empty dayRecords → return all empty/null aggregates
  - All rejected days → return all empty/null aggregates
  - Single day → avg = that day's values; min = max = same day with date

Pure function: operates on input array only, does NOT mutate inputs, does NOT call eventLog/settings/storage.

Use extractTime helper (already defined in metrics.js) for time access.
