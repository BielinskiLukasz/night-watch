Current implementation (lines ~140-146):
```javascript
export function sleepAfterActivityFactor(day, prevDay) {
  if (prevDay == null) return null;
  const sleep      = combinedSleepNap(day);
  const prevActivity = totalActivity(prevDay);
  if (sleep == null || prevActivity == null || prevActivity === 0) return null;
  return sleep / prevActivity;
}
```

Issue: On a no-nap day (napStart and napEnd both null), combinedSleepNap(day) returns sleepDuration(day) correctly, so this function should already work. However, if totalActivity(day) is null (due to missing wake), the formula fails.

Fix: When day has no nap (napStart and napEnd both null), ensure the formula uses sleepDuration(day) directly (which combinedSleepNap already does). The existing code should work IF totalActivity properly handles no-nap days.

Most likely, the fix is a no-op (the code already works), or a minor logic adjustment if totalActivity is the issue.
