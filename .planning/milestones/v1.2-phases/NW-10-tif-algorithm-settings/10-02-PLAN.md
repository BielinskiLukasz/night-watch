    Create js/lib/forecast-tif.js. Structure:

    === Imports ===
    Import from './forecast.js': timeToMinutes, minutesToTime, percentile, detectColdStart
    Import from './metrics.js': sleepDuration, napDuration, activityBeforeNap, activityAfterNap, dayLength, combinedSleepNap

    === TIF_CONFIG (Object.freeze per CLAUDE.md) ===
    ```js
    const TIF_CONFIG = Object.freeze({
      ROUND_MINUTES: 5,
    });
    ```

    === extractTime(slot) — local helper (same as forecast.js) ===
    Copy from forecast.js lines 345–353. Returns HH:MM string or null.

    === trimmedMinMax(values, trimPct, manualExcludedCount) ===
    Implements B-21 Step 1:
    - values: sorted array of numeric minutes-since-midnight
    - trimPct: percentage (0–40)
    - manualExcludedCount: number of values already excluded manually
    - N = values.length (before trim)
    - budget = Math.max(0, Math.floor(N * trimPct / 100) - manualExcludedCount)
    - low = Math.floor(budget / 2)   (remove from bottom)
    - high = Math.ceil(budget / 2)    (remove from top)
    - trimmed = values.slice(low, values.length - high) (or values if high === 0)
    - If trimmed is empty → return null
    - Returns { min: trimmed[0], max: trimmed[trimmed.length - 1] }
    Export this function for unit testing.

    === computeIntersection(windows) ===
    B-21 Step 2 — intersection of multiple {min, max} windows (all numeric minutes):
    - finalStart = Math.max(...windows.map(w => w.min))
    - finalEnd   = Math.min(...windows.map(w => w.max))
    - If finalStart > finalEnd → isLowConfidence = true, use union instead:
        finalStart = Math.min(...windows.map(w => w.min))
        finalEnd   = Math.max(...windows.map(w => w.max))
    - Returns { min: finalStart, max: finalEnd, isLowConfidence }

    === applyPrecision(min, max, precisionTarget) ===
    B-21 Step 4 display logic:
    - algRange = max - min (minutes)
    - If algRange <= precisionTarget:
        precisionScore = 100
        dispMin = min, dispMax = max
    - Else:
        precisionScore = Math.round(precisionTarget / algRange * 100)
        center = (min + max) / 2
        dispMin = center - precisionTarget / 2
        dispMax = center + precisionTarget / 2
    - Returns { precisionScore, algRange, dispMin, dispMax }

    === buildHistoricBand(times, trimPct, manualExcluded) ===
    Given a sorted numeric array, applies trimmedMinMax and returns {min, max} or null.

    === buildDurationBand(durations, anchorMinutes, trimPct, manualExcluded) ===
    Given sorted duration array (minutes), applies trimmedMinMax, then projects:
    - Returns { min: anchorMinutes + durMin, max: anchorMinutes + durMax } or null

    === resolveAnchor(eventType, dayRecords, tifPredictions) ===
    B-21 anchor rule:
    - Finds the latest event in dayRecords by scanning allEvents arrays (same as selectNextEvent pattern)
    - If the latest event is of type eventType → extract its actual HH:MM and return timeToMinutes(time)
    - Otherwise → use tifPredictions[eventType].central (the midpoint HH:MM), convert to minutes
    - If no prediction exists for that type → return null

    === tifForecast(dayRecords, settings) — main export ===
    1. Cold-start gate: call detectColdStart(dayRecords, settings.minDays). If isColdStart, return same shape as forecast.js cold-start result.
    2. Slice to windowDays (same as forecast.js rolling window logic).
    3. Separate rejected vs. non-rejected days:
       - rejected days inform the manualExcluded count per event type
       - all days (including rejected) contribute their events to the value arrays (TIF-11: manually rejected events count against trim budget before auto-trim)
       - For each event type, manualExcluded = count of days where day.rejected === true AND that event slot is non-null
    4. For each event type, collect sorted numeric arrays:
       - wakeMinutes, bedtimeMinutes, napStartMinutes, napEndMinutes (sorted ascending)
       - sleepDurations, napDurations, actBeforeNap, actAfterNap, dayLengths, combinedDurations (sorted ascending)
    5. Compute predictions in order: wake → napStart → napEnd → bedtime (anchor chain)
       
       **Wake prediction (TIF-04):**
       - bedtimeAnchor = resolveAnchor('bedtime', dayRecords, {}) — on the first pass we don't have TIF predictions yet; use the actual logged bedtime if it's the latest event, otherwise fall back to null (skip duration bands if anchor unavailable)
       - Window 1: Historic wake-up band = buildHistoricBand(wakeMinutes, trimPct, manualExcludedWake)
       - Window 2: Sleep-length band = if bedtimeAnchor != null: buildDurationBand(sleepDurations, bedtimeAnchor, trimPct, 0)
       - Window 3: Combined sleep+nap band = if bedtimeAnchor != null: buildDurationBand(combinedDurations, bedtimeAnchor, trimPct, 0)
       - Collect non-null windows with their labels (sourceWindows array)
       - Call computeIntersection(windows) to get {min, max, isLowConfidence}
       - Call applyPrecision(min, max, settings.precisionTarget) to get display values
       - Build wakePred object with all required fields
       
       **Nap-start prediction (TIF-05):**
       - wakeAnchor = resolveAnchor('wake', dayRecords, { wake: wakePred }) — if wake is the latest logged event, use actual; else use wakePred.central
       - Window 1: Historic nap-start band
       - Window 2: Activity-before-nap band = if wakeAnchor != null: buildDurationBand(actBeforeNap, wakeAnchor, trimPct, 0)
       - Compute intersection → napStartPred

       **Nap-end prediction (TIF-06):**
       - napStartAnchor = resolveAnchor('napStart', dayRecords, { wake: wakePred, napStart: napStartPred })
       - Window 1: Historic nap-end band
       - Window 2: Nap-length band = if napStartAnchor != null: buildDurationBand(napDurations, napStartAnchor, trimPct, 0)
       - Compute intersection → napEndPred

       **Bedtime prediction (TIF-07):**
       - wakeAnchor2 = resolveAnchor('wake', dayRecords, { wake: wakePred, napStart: napStartPred, napEnd: napEndPred })
       - napEndAnchor = resolveAnchor('napEnd', dayRecords, { wake: wakePred, napStart: napStartPred, napEnd: napEndPred })
       - Window 1: Historic bedtime band
       - Window 2: Day-length band = if wakeAnchor2 != null: buildDurationBand(dayLengths, wakeAnchor2, trimPct, 0)
       - Window 3: Activity-after-nap band = if napEndAnchor != null: buildDurationBand(actAfterNap, napEndAnchor, trimPct, 0)
       - Compute intersection → bedtimePred

    6. Return { isColdStart: false, wake: wakePred, napStart: napStartPred, napEnd: napEndPred, bedtime: bedtimePred }

    **Return shape for each prediction object:**
    ```js
    {
      central: minutesToTime(dispMin + (dispMax - dispMin) / 2),  // midpoint of displayed window
      min:     minutesToTime(dispMin),   // displayed window start
      max:     minutesToTime(dispMax),   // displayed window end
      precisionScore,                    // 0–100 integer
      isLowConfidence,                   // boolean
      algRange,                          // raw algorithm range in minutes
      algMin:  minutesToTime(algMinRaw), // algorithm raw start (before narrowing)
      algMax:  minutesToTime(algMaxRaw), // algorithm raw end (before narrowing)
      sourceWindows,                     // array of { label: string, min: string, max: string }
    }
    ```
    When no windows can be computed (e.g., event type never recorded): return { central: null, min: null, max: null, precisionScore: null, isLowConfidence: false, algRange: null, algMin: null, algMax: null, sourceWindows: [] }

    **sourceWindows labels** (from CONTEXT.md "Claude's discretion" + BACKLOG.md B-21 Step 3 naming):
    - Wake: 'Historic wake-up band', 'Sleep-length band', 'Sleep + nap combined band'
    - Nap-start: 'Historic nap-start band', 'Activity-before-nap band'
    - Nap-end: 'Historic nap-end band', 'Nap-length band'
    - Bedtime: 'Historic bedtime band', 'Day-length band', 'Activity-after-nap band'

    **5-minute rounding:** All minutesToTime calls apply the ROUND_MINUTES=5 rounding from minutesToTime (already built into that function). No extra rounding needed.
