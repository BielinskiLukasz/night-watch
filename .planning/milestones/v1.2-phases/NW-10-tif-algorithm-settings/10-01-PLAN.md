    Create js/lib/metrics.js as a pure-function module. Import timeToMinutes from './forecast.js'. Define a local extractTime(slot) identical to forecast.js lines 345–353 (handles null, object.at, bare string).

    The six exported functions (all accept a single day record, all return number|null):

    1. sleepDuration(day):
       - Requires day.wake and day.bedtime both non-null
       - Computes wake_minutes - bedtime_minutes
       - Night sleep crosses midnight: if result < 0, add 24×60
       - Returns minutes or null

    2. napDuration(day):
       - Requires day.napStart and day.napEnd both non-null
       - Returns napEnd_minutes - napStart_minutes (always positive, nap does not cross midnight)
       - Returns null if either is missing

    3. activityBeforeNap(day):
       - Requires day.wake and day.napStart both non-null
       - Returns napStart_minutes - wake_minutes
       - If result < 0 add 24×60 (defensive — should not happen in practice)
       - Returns null if either is missing

    4. activityAfterNap(day):
       - Requires day.napEnd and day.bedtime both non-null
       - Returns bedtime_minutes - napEnd_minutes
       - If result < 0 add 24×60 (bedtime after midnight relative to nap-end)
       - Returns null if either is missing

    5. dayLength(day):
       - Requires day.wake and day.bedtime both non-null
       - Returns bedtime_minutes - wake_minutes; if negative add 24×60
       - Note: this is the same formula as sleepDuration but semantically named for awake-window use in the TIF day-length window
       - Returns null if either is missing

    6. combinedSleepNap(day):
       - Requires sleepDuration(day) != null AND napDuration(day) != null
       - Returns sleepDuration(day) + napDuration(day)
       - Returns null if either component is null

    Module header comment: document the D10-01 and D10-02 decisions, note that Phase 11 extends this file with ratio metrics. No per-function JSDoc comments longer than one line.

    Object.freeze is not needed here — no config objects, only exported functions.
  </action>
