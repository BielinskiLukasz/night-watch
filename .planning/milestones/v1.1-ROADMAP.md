## Overview

Nightwatch v1.1 UX Polish reduced daily logging friction and improved visual clarity across the Today, History, and prediction screens. A single phase (Phase 9) delivered 9 requirements: a new "Confirm before logging" workflow, a "Save more" button for rapid bulk entry, History edit-mode toggle, prediction card collapse for probability-band fallback, button repositioning, and a hero card label — all backed by a TDD-first approach with 36 new unit/integration tests and a fully rewritten probability-band E2E spec.

---

## Accomplishments

1. **History edit-mode toggle** (UI-07) — Edit/delete/rejected controls hidden by default; "Edit history" toggle button in the toolbar reveals them; toggle state resets when navigating away from the History tab
2. **"+ Add event" repositioned + hero label** (UI-08, UI-10) — "Add event" button moved above prediction cards and hero card on the Today screen; hero card now shows an explicit "Next Predicted Event" label
3. **Prediction card collapse** (UI-09) — Probability-band forecast cards (±delta > max_delta) collapsed to a compact single-line summary (label • time window ↓) by default; tapping expands to full probability list; tapping again collapses
4. **Confirm-before-logging** (CFG-10, LOG-10) — New "Confirm before logging" toggle in the Time & Day settings group; when ON, quick-log buttons open the manual-entry dialog pre-filled with the current time and clicked event type rather than logging instantly
5. **"Save more" button** (LOG-11) — Manual-entry dialog gains a "Save more" button that saves the current event, keeps the dialog open, and advances the type through Wake → Nap start → Nap end → Bedtime → Wake; date increments by one day after saving Bedtime
6. **E2E test rewrite + scratch cleanup** (PLAT-12, PLAT-13) — Probability-band E2E spec fully rewritten with a 32-day 4-event-type fixture (128 events); 3 new Phase 9 UI tests (collapse default, expand/collapse interaction, hero label); `nw-research-test/` scratch directory removed from repository root

**Key decisions:**
- `confirmBeforeLogging: false` default — instant-log remains the fast path (D9-13)
- `SAVE_MORE_SEQUENCE = ['wake','napStart','napEnd','bedtime']` — fixed advancement order (D9-10)
- `advanceDateByOneDay` uses T12:00 noon to avoid DST boundary ambiguity (D9-11)
- Module-level `_saveMoreHandler` ref + `removeEventListener` prevents listener accumulation
- `editMode` local to `mountHistoryScreen` closure — resets on each remount (D9-04 bug found + fixed in UAT)
- `clock` dep threaded to `mountTodayScreen` via `app.js`; tests use data-layer only
- hasProbBand collapse state not tracked — `replaceChildren()` in `renderForecastSection()` resets on every re-render (D9-06)

**Bugs found and fixed during UAT:**
- Bug 1 (UI-07): Edit mode not resetting on tab switch. Fixed by returning `resetEditMode()` from `mountHistoryScreen` and calling it from `app.js` `onTabChange`. (commit `3866bac`)
- Bug 2 (LOG-10): Confirm-before-logging dialog not pre-filling type/time. Fixed by broadening `openManualEntry` pre-fill condition from `mode==='edit' && existing` to `if (existing)`. (commit `cbd225f`)
