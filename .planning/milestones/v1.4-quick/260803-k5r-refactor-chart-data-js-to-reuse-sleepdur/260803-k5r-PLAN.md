## Objective

Eliminate redundant duration-calculation code in chart-data.js by importing and reusing `sleepDuration()` and `napDuration()` from metrics.js.

**Why:** Single source of truth for duration logic; consistent behavior across the app; reduced maintenance burden.

## Context

- `metrics.js` exports `sleepDuration(day)` and `napDuration(day)` — both pure, tested functions
- `chart-data.js` currently duplicates this logic via private `computeSleepHours()` and inline nap-length arithmetic
- Three call sites for sleep duration; one aggregation in `buildNapStats()`
