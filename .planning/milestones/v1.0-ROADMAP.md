## Overview

Nightwatch v1.0 is a vanilla-JS, offline-first PWA for tracking a single subject's sleep (night sleep + naps) and forecasting their next sleep events with explicit uncertainty handling and prediction-accuracy scoring. Built in 35 days across 8 vertical-slice phases, from bare logging scaffold through PWA hardening.

---

## Accomplishments

1. **Complete sleep logging** — 4 quick-log buttons, manual entry, edit/delete, 5-minute precision, subjective-night grouping (configurable cutover hour), single-nap-per-day constraint with overflow surfacing
2. **Full settings system** — subject display name, max_delta, min_days, rolling-window length, stat blend (median/mean/configurable), cutover hour, 12h/24h time format; all persisted across reloads
3. **Forecast engine** — 4-event predictions (wake, bedtime, nap start, nap end) with min/max bands; probability-band fallback when ±delta > max_delta; cold-start gate; reactive updates on every log or reject change
4. **History screen** — scrollable table with per-row edit/delete and "rejected" outlier toggle; rejection scoped to forecast re-computation via settings store
5. **Import/Export** — CSV import (Polish sen.xlsx column schema, BOM-strip, fuzzy headers), JSON round-trip import, JSON export, file-as-truth storage model
6. **Life stages** — named date-range stages with inline CRUD in Settings modal, stage-selector on Today screen, scope-to-stage forecast filtering via `filterDayRecordsByStage()`
7. **Charts + Accuracy** — 5 SVG visualizations (sleep length over time, time bands, calendar heatmap, nap pattern, activity correlation) + 3-metric accuracy dashboard + bottom-nav between all 4 screens
8. **PWA hardening + TDD scaffold** — PWA manifest + service worker + offline-first + file:// support; GitHub Pages deployment; calm visual identity; 495-test TDD scaffold (unit + integration + Playwright E2E); security-smoke invariants
