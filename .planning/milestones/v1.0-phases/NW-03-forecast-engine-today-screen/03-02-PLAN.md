<objective>
Extend the forecast algorithm to handle high-uncertainty fallback (probability bands) and cold-start gating.

**Purpose:** PRED-05 and PRED-06 add nuance to the basic percentile forecast. When uncertainty is high (band width > maxDelta), switch UI representation from point + band to a probability table. When history is thin (< minDays valid days), suppress predictions entirely and surface an explicit message. This wave extends the pure-logic layer without touching the UI; rendering comes in Phase 01-02.

**Output:** `forecast()` now returns an optional `probabilityBand` field when high-uncertainty fallback is active, and a `isColdStart` flag when gating applies. Tests verify the thresholds and output shapes.
</objective>
