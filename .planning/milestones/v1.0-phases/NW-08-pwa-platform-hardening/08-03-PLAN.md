| SW postMessage → app | Browser enforces same-origin; SKIP_WAITING message has no injectable payload |
| localStorage read (file note key) | Value is read as truthy/falsy only — no eval or code execution from stored value |
| DOM text (banner, note) | Text set via textContent only — no user input; no XSS vector |
