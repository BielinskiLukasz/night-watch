<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| settings save path | User-supplied form data enters validateSettings — must not bypass bounds |
| settings load path | localStorage blob enters migrateV1ToV2 + validateSettings — must not crash on corrupt data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Tampering | validateSettings (save mode) | mitigate | Strict bounds per RULES on all 9 fields; no field can bypass validation to reach settings.update() |
| T-2-02 | Tampering | validateSettings (load mode) | mitigate | Per-field default-on-invalid with console.warn; corrupt blob never crashes app, never silently preserves invalid value |
| T-2-03 | Tampering | migrateV1ToV2 | mitigate | Throws on version ≥ 3; treats null/undefined as fresh install (safe); v1→v2 is one-way idempotent |
| T-2-04 | Tampering | DEFAULT_SETTINGS | mitigate | Object.freeze — mutation attempts throw in strict mode; callers receive spread copies, not the frozen object |
| T-2-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this plan — pure node:test built-in; no install step |
</threat_model>
