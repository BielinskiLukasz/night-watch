## v1.1 Requirements

All 9 requirements delivered in Phase 9 (UX Polish).

### Logging (LOG)

- [x] **LOG-10**: When "Confirm before logging" is ON, tapping a quick-log button opens the full manual-entry dialog pre-filled with the current time and that event type; user can adjust any field before saving — **DELIVERED** (Plan 09-04; UAT test 10 ✅)
- [x] **LOG-11**: Manual-entry popup includes a "Save more" button that saves the current event, keeps the popup open, and pre-fills the form for the next event type in sequence (Wake → Nap start → Nap end → Bedtime → Wake); after saving Bedtime, the date advances by one day and the type resets to Wake — **DELIVERED** (Plan 09-05; UAT tests 11–13 ✅)

### Configuration (CFG)

- [x] **CFG-10**: Settings modal Time & Day group includes a "Confirm before logging" toggle; when OFF (default), quick-log buttons log instantly at the current time; when ON, they open the pre-filled manual-entry dialog — **DELIVERED** (Plan 09-04; UAT tests 8–9 ✅)

### UI (UI)

- [x] **UI-07**: History table renders without edit/delete/rejected controls by default; an "Edit history" toggle button in the history toolbar shows/hides all controls; toggle state resets when navigating away from the History tab — **DELIVERED** (Plan 09-02; UAT tests 1–3 ✅; bug fixed commit `3866bac`)
- [x] **UI-08**: "Add event" button is positioned at the top of the Today screen, above the prediction cards and hero card — **DELIVERED** (Plan 09-01; UAT test 4 ✅)
- [x] **UI-09**: Prediction cards in probability-band fallback (±delta > max_delta) render as a compact collapsed single line showing event label, time window, and an expand chevron [↓]; tapping a collapsed card expands it to the full card; tapping an expanded uncertain card collapses it — **DELIVERED** (Plan 09-03; UAT tests 6–7 ✅)
- [x] **UI-10**: Hero card on the Today screen shows an explicit "Next Predicted Event" label above the predicted time and event type (TD-2) — **DELIVERED** (Plan 09-01; UAT test 5 ✅)

### Platform / Quality (PLAT)

- [x] **PLAT-12**: Probability-band E2E test rewritten to use a realistic fixture with 30+ days of all four event types (wake, nap-start, nap-end, bedtime), validating fallback rendering in realistic scenarios (TD-3) — **DELIVERED** (Plan 09-06; 7 E2E tests passing)
- [x] **PLAT-13**: `nw-research-test/` scratch directory removed from the repository root (TD-1) — **DELIVERED** (Plan 09-01; confirmed absent)
